# 編譯與代表性行為驗證

## 環境與方法

驗證日期：2026-10-05。編譯器：`gcc.exe (GCC) 7.4.0`，Windows MinGW 工具鏈。每份 C 程式獨立編譯，不將不同版本連結在一起。

```text
-std=gnu11 -D_POSIX_C_SOURCE=200809L -O0 -Wall -Wextra
link: -lm
```

使用 `tools/verify_course.py` 複製程式至獨立暫存目錄、重新編譯並執行新產生的 EXE。小型圖與輸入由工具建立；沒有執行原課程資料夾內的舊二進位檔。Windows 換行先正規化，再比對輸出。

這些比對大多是代表性輸出檢查，不是形式化證明或全面的 property-based test。稀疏矩陣轉置與 Dijkstra 的其他 source 有執行輸出，但沒有逐一以獨立演算法驗算所有結果。
